## 🛠️ Featured projects

### 🛡️ [Agent Evaluator](https://github.com/imnaviya18/agent-evaluator-hackathon)
An offline, local-first framework that tests AI agents safely before they reach production. Nothing leaves your machine.
- **Mock tool suite:** simulated flight, hotel, payment, SQL, file system, shell and email tools
- **Security monitor and guardrails:** detects prompt injection, jailbreaks and shell escapes, and redacts PII
- **Attack and scenario generator:** creates fuzzing inputs and multi-step agent tasks
- **Failure classifier:** labels tool errors and loops using local Ollama models or heuristic fallbacks
- **Trace and replay harness:** step-by-step recordings that can be replayed exactly
- **Two interfaces:** a Streamlit dashboard and a React + Vite web app
- **Storage:** SQLite by default, PostgreSQL optional

`Python` `Flask` `FastAPI` `Streamlit` `React` `Ollama` `SQLite`

### 🌾 [KAROBAAR](https://github.com/imnaviya18/aspire-for-her-logitech-hackatho)
A generative AI business-planning assistant for **rural women entrepreneurs**, built for the *Aspire For Her × Logitech National Hackathon 2026*. For the Grand Finale, it became a **Digital Sales Journey Planner** that helps an entrepreneur run a **₹2,000, 14-day digital sales campaign** on her own.
- Picks a realistic target customer
- Builds a day-by-day Instagram content plan
- Chooses a low-cost purchase path (Instagram Shop or WhatsApp Catalog)
- Plans safe UPI payment collection and delivery fallbacks
- Allocates the full budget and runs a mid-campaign check-in on Day 7
- Separates confirmed information from assumptions

### 🔗 [Covenant](https://github.com/imnaviya18/covenant)
